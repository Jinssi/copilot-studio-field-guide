# Three cards for the Studio test pane

Start a **new test session for each row**. Record the topic and the reply, not just a tick.
The lab checker inspects files; it does not run any of these conversations.

| Card | Type this | What to observe |
| --- | --- | --- |
| P1 / pickup | Where do I pick up a loan projector? | Desk pickup fires. Its message says Map Room, Monday to Friday, 09:00 to 17:00 local time. It does not mention the North Counter. |
| P2 / boundary | Is there after-hours projector pickup? | Desk pickup fires and explicitly says there is no after-hours pickup; no fallback location, form or booking is offered. |
| N1 / different intent | How do I reset my password? | Desk pickup does not fire. A fallback, clarification or different topic is fine. Do not demand a particular fallback sentence. |

Stretch: try a paraphrase the designer did not put in the triggers. Record the actual result, even if it contradicts your prediction.
