# ★ Level One · Find the topic

<span class="kicker">Maker’s bench · 45 minutes · starts after setup</span>

**Work order:** fix an incorrect pickup location without changing anything else. This is a small job on purpose: if you cannot tell which line made the difference, you cannot review the next change.

| Lab | What you do | What you keep |
| --- | --- | --- |
| [01 · Follow a question](./map) · 10 min | Trace a visitor's phrase through a topic to a message. | Three file or node names. |
| [02 · Clone a Studio agent](./clone) · 20 min | Create a disposable desk agent and find its local definition, or map the supplied topic offline. | The correct topic path for your lane. |
| [03 · Make a one-line fix](./edit) · 15 min | Have GitHub Copilot propose one edit. Reject anything larger. | A commit that moves the desk. |

**One-star check:** from a clean practice worktree, show the old reply, the new reply, and the unchanged trigger. Explain why a visitor would still hear the old reply in an untouched Studio environment. [Set up first](../start) if you do not yet have the desk card.
