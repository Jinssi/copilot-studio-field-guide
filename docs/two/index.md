# ★★ Level Two · Build the pair

<span class="kicker">Authoring bench · 60 minutes · requires Level One</span>

The Map Room has opening hours. The visitor needs them; the agent doesn't need a credit card number, a booking system or a new personality. Build one helper to write the change and another to spot an overreach.

| Lab | What you do | What you keep |
| --- | --- | --- |
| [04 · Create an author](./author) · 20 min | Ask GitHub Copilot to create a project-local authoring agent and put it to work. | One `.agent.md` profile and a policy-backed message. |
| [05 · Create a reviewer](./reviewer) · 20 min | Configure a read-only second reader and test it against a deliberately false claim. | A reviewer profile and an actionable finding. |
| [06 · Test in Studio](./test) · 20 min | Separate review, apply, runtime test and release. | Three evidence rows with honest results. |

**Two-star check:** show which helper can edit, which cannot, and what evidence a human still has to supply. If you are in the local lane, your two-star **rehearsal** ends with predictions, not claims of a successful Studio run.
