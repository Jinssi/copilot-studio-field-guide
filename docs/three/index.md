# ★★★ Level Three · Share the reviewer

<span class="kicker">Maintainer’s bench · 65 minutes · requires Level Two</span>

A second project wants your reviewer. “I'll email you the latest copy” works beautifully until Tuesday. Make one source of truth, give the second project an identifiable revision, and practice removing a bad update without touching the Studio agent.

| Lab | What you do | What you keep |
| --- | --- | --- |
| [07 · Build a catalog](./catalog) · 20 min | Create a separate Git repository for reusable profiles; choose explicit distribution or native organization discovery. | A catalog, commit and consumer receipt. |
| [08 · Roll out a revision](./rollout) · 25 min | Pilot a new reviewer in a second project while the first stays pinned. | Two different, identifiable revisions and a tested rollback. |
| [09 · Hand off the desk](./handoff) · 20 min | Give the next maker the exact profile, test evidence and release decision. | A reviewable handoff and a three-star checklist. |

The main path works on a personal account, entirely on disk. You do **not** need to create an organization, change enterprise policies, or publish a real company's agent library to learn this pattern.
