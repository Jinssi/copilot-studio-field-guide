# Side labs

These are independent of the star count. Each one says which materials it needs; you do not have to finish all three levels first.

| Side lab | Start with | Leave with |
| --- | --- | --- |
| [Build a new Studio agent from local files](./new-agent) · 25 min | GitHub Copilot, the preview Studio CLI and an authorized development environment | A new agent definition authored in the editor and a verified, unpublished Studio draft. |
| [Personal or project?](./scope) · 10 min | VS Code + GitHub Copilot and a reviewer profile | An observed scope boundary across two folders. |
| [When the cloud changed first](./drift) · 15 min | A disposable connected agent, or just the practice topic | A conflict decision that preserves a teammate's work. |
| [Give a GitHub issue to the author](./github) · 15 min | An approved private synthetic repo and access to GitHub's cloud agent | A reviewed GitHub proposal, not a Studio deployment. |
