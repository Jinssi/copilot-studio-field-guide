# Lantern Desk agent library

A working two-revision catalog for Jinssi's [Copilot Studio Field Guide](https://jinssi.github.io/copilot-studio-field-guide/three/catalog.html). This branch deliberately contains a root `agents/` directory, not a Studio agent definition and not an automatically installed GitHub organization catalog.

Read the [reviewer profile](agents/studio-reviewer.agent.md) before adopting it. In an ordinary consumer project its active destination is `.github/agents/studio-reviewer.agent.md`. In the main workshop you build this history yourself; in a demonstration you can compare the published `catalog-v1` and `catalog-v2` tags and pin the exact commit you reviewed.
